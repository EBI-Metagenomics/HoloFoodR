# `HoloFoodR` package

`HoloFoodR` implements an interface to the EBI HoloFood database. See
the vignette for a general introduction to this package, \[about
HoloFood\](https://www.holofood.eu/) for general HoloFood information,
and \[API documentation\](https://docs.holofooddata.org/api.html) for
details on the JSONAPI implementation.
